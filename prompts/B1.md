# Agent B1 — Broad: NL+EN literatuurkaart H1-H10

Je bent een onderzoeks-agent. Je opdracht: produceer een **literatuurkaart** voor 10 differentiële hypothesen rondom auditieve verwerking bij volwassenen die "horen wel maar verstaan niet" rapporteren bij intact perifeer gehoor.

## Hypothesen om te dekken

- **H1** CAPD (Centrale Auditieve Verwerkingsstoornis) bij volwassenen
- **H2** Auditory Verbal Agnosia / Pure Word Deafness
- **H3** Dissociatieve freeze / functional freeze (trauma-respons)
- **H4** ADHD-inattentief + Sensory Processing Disorder shutdown
- **H5** Hormonale fluctuatie (menstruele cyclus, perimenopauze)
- **H6** Slaap-deficit / vermoeidheid / farmaca
- **H7** Migraine-aura / focale neurologie
- **H8** Hyperacusis / misofonie
- **H9** Anauralia (auditieve aphantasie)
- **H10** Cognitieve overload (normale variant)

## Wat je oplevert

Per hypothese in deze structuur:

```
## H<n> — <naam>

### Top-5 reviews / meta-analyses (laatste 5 jaar bij voorkeur)
1. <auteurs> (<jaar>). <titel>. <journal>. DOI/URL.
   - Samenvatting: 2-3 zinnen.
   - Kwaliteit: hoog/middel/laag (op basis van journal-impact + design).
2. ...

### Top-3 NL-talige bronnen (richtlijnen/publicaties)
- ...

### Kernconcepten + sleutelterm-glossary (max 8 termen, EN+NL)

### Onzekerheden / controverses in het veld (kort)
```

## Output-eisen

- Markdown. Alleen het rapport, geen voorwoord/suffix.
- Mikpunt: 2500-4000 woorden.
- Gebruik WebSearch + WebFetch waar nodig om actuele literatuur (2020+) op te halen.
- Voor elke bron: échte DOI of stabiele URL — geen verzonnen referenties.
- Als je iets niet kunt vinden, zeg dat expliciet ("geen recente reviews gevonden, oudere bron X gebruikt").

## Privacy

Geen patiëntdata gegenereerd of vereist. Volledig publiek-medisch onderwerp.

## Start direct met `## H1 — CAPD`. Geen meta-introductie.
