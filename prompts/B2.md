# Agent B2 — Broad: Zorgpad NL voor centrale auditieve klachten

Je bent een onderzoeks-agent. Je opdracht: maak een concrete NL-zorgpad-kaart voor een volwassene die zich bij de huisarts meldt met "ik hoor wel maar versta niet" bij normale audiometrie.

## Wat je oplevert

```
## 1. Eerstelijn (huisarts)
- Welke screeners + vragen kan de huisarts inzetten?
- Welke audiometrie wordt routinematig gedaan?
- Wanneer wel/niet verwijzen?

## 2. KNO / audioloog (basis-audiologie)
- Welke tests buiten pure-tone (tympanometrie, OAE, ABR)?
- Wanneer doorverwijzing naar APD-poli?

## 3. APD-poli's / klinische audiologie volwassenen NL
- Lijst NL-centra met adult-APD-diagnostiek (AUMC, Radboudumc, MUMC, Erasmus, UMCG, Pento, etc.) — verifieer welke daadwerkelijk volwassenen aannemen
- Per centrum: contact, wachttijd indien publiek bekend, vergoedingsregeling, verwijsbrief-eisen
- Welke testbatterijen worden gebruikt (NL-versies SCAN-3, Plomp/Mimpen, DDT)

## 4. Klinisch psycholoog — trauma-georiënteerd (H3-pad)
- Verwijscriteria
- Vergoeding GGZ (basis-GGZ vs gespecialiseerd)
- NL behandelvormen: EMDR, SE (Somatic Experiencing), schemagericht, IFS
- Wachttijden, alternatieven (zelfstandig gevestigde vs instellingen)

## 5. Psychiater / volwassen-ADHD-screening (H4-pad)
- NL volwassen-ADHD-zorgpad
- Diagnostische instrumenten
- Wachttijden, alternatieven

## 6. Gynaecoloog / endocrinoloog (H5-pad)
- Wanneer onderzoek hormoonprofiel zinvol bij auditieve fluctuatie?
- Welke parameters meten?

## 7. Neuroloog (H2/H7-pad)
- Indicaties voor MRI hersenen
- Hoofdpijn/aura-anamnese protocol

## 8. Beslisboom-samenvatting
Compacte tekstuele beslisboom: bij welke score-combinatie naar welke specialist.

## 9. Verwijsbrief-template
Concept-tekst (Nederlandstalig) die een huisarts kan gebruiken nadat patiënt een eigen empirisch onderzoek heeft uitgevoerd (audiometrie + centrale-auditieve batterij + LOG + vragenlijsten).
```

## Output-eisen

- Nederlands, formeel maar leesbaar.
- Markdown. Alleen het rapport, geen voorwoord/suffix.
- Mikpunt: 2500-3500 woorden.
- Gebruik WebSearch+WebFetch op richtlijnen NHG, FENAC, NVKF, NVA-richtlijn, vereniging-AAA, etc.
- Voor elke claim over wachttijd/vergoeding: ófwel bron citeren, ófwel expliciet "schatting" markeren.
- Geen patiëntdata.

## Start direct met `## 1. Eerstelijn (huisarts)`. Geen meta-introductie.
