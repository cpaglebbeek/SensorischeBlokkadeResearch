# Agent D4 — Deep: T1-T6 Web Audio API implementatie-skeletten

Je bent een onderzoeks-agent. Je opdracht: produceer concrete, werkende **JavaScript-code-skeletten** voor 6 zelf-test instrumenten in een browser-app, geschreven voor de Web Audio API. Output moet zonder library-afhankelijkheden bouwen op `OscillatorNode`, `AudioBufferSourceNode`, `BiquadFilterNode`, `StereoPannerNode`, `GainNode`, `OfflineAudioContext`, `MediaRecorder`.

## Context

Het doelproject is "Wat Hoor Ik?" (wathoorik.nl), single-page vanilla HTML/CSS/JS, geen build-pipeline. Bestaande code-stijl is procedureel met state-object. Bestaande tests (audiometrie) gebruiken al `OscillatorNode + StereoPannerNode + GainNode` met log-curve `levelToGain(pct)`.

## Te bouwen tests

### T1 — Speech-in-Noise (SIN)
- Adaptieve test, 1-up/1-down regel of 1-up/2-down
- 4-talker babble als achtergrond (loop AudioBuffer)
- Doel-zin als AudioBuffer (preloaded WAV)
- Per trial: SNR-aanpassing
- Output: SRT50% in dB SNR
- UI: zin tonen na afspelen, user typt na, scoring via Levenshtein op woord-niveau (3-of-5-key-words klassiek)

### T2 — Gaps-in-Noise (GIN)
- Generated wit ruis 6 sec via `OfflineAudioContext + AudioBufferSourceNode`
- 0-10 silent gaps random positioned, duraties 2/3/4/5/6/8/10/12/15/20 ms
- User drukt spatie bij stilte
- Detectie: press binnen 1000 ms na gap-start = hit
- Output: drempel = kortste gap die in >=4 van 6 trials gedetecteerd wordt

### T3 — Dichotic Digits Test (DDT)
- Per trial: 2-3 cijfers L + 2-3 verschillende cijfers R simultaan
- Cijfers als preloaded AudioBuffer per oor
- User typt alle gehoorde cijfers in volgorde
- Output: % correct L, % correct R, right-ear advantage

### T4 — Environmental-vs-Words
- 20 omgevingsgeluiden (klop, fluit, hond, klok, water, glas, etc.) + 20 NL-woorden
- Beide bij identieke SNR (multi-talker babble of pink noise)
- User multiple-choice (4 opties per item) of vrij typen
- Output: % correct env, % correct words, differentiële score

### T5 — Repetition + Write
- Zin (preloaded AudioBuffer) afgespeeld
- User klikt "ik kan dit naspreken" (MediaRecorder start) of "ik kan dit niet horen"
- User typt zin in textarea
- Daarna: zelfde zin als geschreven tekst getoond, user spreekt na (MediaRecorder)
- Output: 4 cellen per trial (rep-na-hoor / write-na-hoor / rep-na-lees / write-na-hoor)

### T6 — Auditory Continuous Performance Task (ACPT)
- 10 min audio-stream van NL-woorden, 1 per 1-2 sec random
- Target-woord (bv "hond") ~20% van trials
- User drukt spatie bij target
- Output: hits %, false alarms %, RT (mean+SD per minuut, drift over 10 min)
